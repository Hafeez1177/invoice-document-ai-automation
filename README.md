# Project 01 — Invoice Automation & Spend Analytics

## Final presentation standard
Four decision-oriented dashboard pages:
1. Executive Overview
2. Spend Analysis
3. Exceptions & Risk
4. Supplier Performance

The browser report is fully self-contained and works locally without an internet connection.

## Power BI
`PowerBI_Source.xlsx` is the prepared source workbook.
`PowerBI_Measures.md` contains the DAX measures and relationship design.

This package does not claim the HTML is a native `.pbix` file. To produce a native Power BI report, import the workbook into Power BI Desktop and apply the included model/measures.

## Data
All records are synthetic portfolio data. They are designed to demonstrate the workflow and decision model without representing real client information.

## Business decisions supported
- cash and overdue payment prioritisation
- supplier concentration
- category spending
- invoice exceptions
- duplicate/high-value review
- supplier performance
